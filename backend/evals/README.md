# Synthetic HCM evaluations

`cases.json` contains 57 deterministic cases using seeded workers and policies, with a fixed as-of date of 2026-10-07. Cases cover all seven source agents, cross-domain composition, self-service scope, exact saved financial values, citations, missing evidence, ambiguous requests and malicious instructions. The runner uses the same orchestrator as the chat API without creating conversations or modifying domain data.

Run `scripts/evaluate_ai.py` from the backend directory with existing `--hr-email` and `--employee-email` actors. Seed Core HR, payroll, benefits and policies first using the documented manual demo commands. The employee must link to DEMO360_P02 for these fixed fixtures. Do not use production data. Failed assertions produce a nonzero exit code and a local JSON report containing case IDs, safe outcomes and checks, not source records or credentials.

Metrics show passing cases divided by applicable cases. Routing, tool selection and status compare explicit expected outcomes. Authorization covers employee cases and denied requests; refusal covers expected denials and missing evidence. Exact-value accuracy compares independently specified JSON values, including decimal strings. Grounding checks expected policy filenames, exact values or explicit absence of citations. Citation precision is a case-level all-citations-valid check against authorized PostgreSQL chunks, not token-level precision. Hallucination checks emitted worker identities and citation provenance; it is not a general natural-language truthfulness score. Injection cases require refusal without tool sections. Secret checks cover forbidden output markers.

These are repeatable fixture checks, not a production benchmark or a claim of model intelligence. They do not measure paraphrase coverage, real-provider quality, statutory correctness or universal injection resistance. Provider/tool/vector-store failures and malicious documents are also exercised in the backend regression suite. No external model judge, API key or new dependency is required. Evaluation reports stay outside Git.
